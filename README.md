# Домашнее задание к лекции «Web-scraping»

Скрипт для парсинга свежих статей с сайта Habr по заданному списку ключевых слов.

## Описание работы
- Программа анализирует всю доступную preview-информацию на странице (текст карточки статьи).
- Реализован корректный поиск точных совпадений слов для кириллицы и латиницы с помощью регулярных выражений.
- Код защищен от зависания сети (`timeout`) и безопасно обрабатывает сетевые ошибки (`requests.RequestException`).

## Инструкция по запуску

1. Установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```

2. Запустите парсер:
```bash
python main.py
```
